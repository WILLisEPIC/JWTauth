# Web Authentication Project

## Project Background

This project was developed for my cyber security module assignment during the bachelor study. This is allso my first web authentication project built with **React.js** and **Node.js**. It implements a secure **JWT-based authentication system** with a strong focus on cybersecurity best practices.

## Key Features

- Session management using JWT system 
- Password hashing using **SHA-256** with **salting**  
- AES-256-CBC encryption to protect token data

## Built With

- **Frontend**: React.js  
- **Backend**: Node.js, Express.js  
- **Database**: SQLite3 
- **Implemented Libaries**: JWT, SHA-256 + salt, AES-256-CBC encryption
